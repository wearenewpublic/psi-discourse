# Connectors

Discourse plugin outlet connectors that inject PSI components into specific locations in the Discourse UI.

## Subdirectories

- **after-title-and-category/** - Contains the slider toggle checkbox shown in the composer when creating a new topic (staff only).
- **composer-fields/** - Contains the slider input shown inside the composer when replying to a slider-enabled topic.
- **topic-above-posts/** - Contains the main slider widget displayed above the post stream on slider-enabled topics.
