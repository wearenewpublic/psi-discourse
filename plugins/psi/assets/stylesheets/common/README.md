# Common Stylesheets

SCSS styles loaded on all platforms (desktop and mobile).

## Files

- **psi.scss** - Core PSI theme: CSS custom properties (purple/salmon palette), IBM Plex Sans typography, post layout matching Figma designs, stance badge styling, composer modal restyling, and hiding Discourse UI elements not in the PSI design (sidebar, topic map, timeline, etc.).

- **psi-slider.scss** - Styles for the discrete slider component and its action buttons. Includes the track, dots, draggable thumb, pulse animation, position labels, and the "Share your thoughts" / "Skip and submit vote" buttons.

- **psi-vote-results.scss** - Styles for the vote results bar chart, including the vertical bars with a purple gradient, percentage labels, user position marker, "Your response" card, and "Update your response" link.
